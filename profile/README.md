<h2>家庭网络配置，关键在六项参数</h2>
<p>把住宅 IP 配到路由器上，真正要动的只有六项：外网接入方式、内网地址段、地址分配范围、DNS、端口转发、以及一些该关掉的功能。其余保持默认即可。</p>
<p>这篇逐项说明设成什么、为什么，以及设错会出现什么现象。</p>

<h2>参数一：外网接入方式</h2>
<p>按你的宽带类型选：拨号、动态地址、或静态地址。选错会直接上不了网，这是最基础的设置。</p>
<p>如果不确定，先看运营商给的资料，或者把路由器设成自动检测。填错的表现是「路由器显示已连接但无法上网」。</p>

<h2>参数二：内网地址段</h2>
<p>默认的网段通常够用。需要注意的只有一点：如果你的运营设备设了静态地址，要确保它在网段内且不与分配范围冲突。</p>
<p>冲突的表现是「设备偶尔能上网、偶尔不能」，很难排查。建议把静态地址统一规划在分配范围之外。</p>

<h2>参数三：地址分配范围</h2>
<p>设备多的时候要留足。默认范围可能只够十台设备，加上手机、平板、智能家居，很快就满。</p>
<p>范围满了的表现是「新设备连不上无线」或者「连上了但拿不到地址」。把范围扩大一档即可解决。</p>

<h2>参数四：DNS</h2>
<p>这一项决定「解析在哪做」。如果解析还在本地，即使流量走了代理，网站也会认为你在本地。</p>
<p>两种做法：在路由器里填目标地区的解析服务器，或者在客户端里开启远程解析。后者更彻底，建议优先。</p>

<h2>参数五：端口转发</h2>
<p>需要从外部访问内网服务时才配。规则要写得尽量窄：只开必要端口、只允许必要来源、用完就删。</p>
<p>长期开着宽泛的转发规则，等于在公网上开了个洞。这是家庭网络最常见的安全隐患。</p>

<h2>参数六：该关掉的功能</h2>
<p>三个建议关闭：远程管理（除非确实需要）、即插即用映射（容易被利用）、以及不用的访客网络。关掉它们不损失功能，但减少了攻击面。</p>

<h2>配好后怎么验证</h2>
<p>四项：设备能正常上网；出口地址符合预期；解析地区与出口一致；目标应用能正常登录。四项都过，配置完成。</p>
<p>验证时要用「实际使用的那台设备」，不要只在自己电脑上测。不同设备读的网络设置可能不同。</p>

<h2>出问题先恢复，别硬改</h2>
<p>配完不能上网，第一动作是恢复上一份可用配置，而不是原地继续调。路由器参数之间有依赖，越改越乱是常态。</p>
<p>建议配置前导出备份。多数固件都有这个功能，用一次能省很多事。</p>

<h2>配置顺序：先通网，再走代理，最后加分流</h2>
<p>三步拆开做，比一次配完再排查高效得多。先确认路由器本身能正常上网，这一步不通过就别往下走；再配置代理并验证出口地址；最后才加分流规则，把该走的和不该走的分开。</p>
<p>一次配完的常见后果是「上不了网」，而这时候你分不清是宽带问题、代理问题还是规则问题，只能从头逐项排除，反而更慢。</p>
<h2>常见问题</h2>
<h3>要不要改路由器的固件</h3>
<p>只有需要分流功能时才考虑。刷机有变砖风险，能用原厂功能解决就不要刷。</p>
<h3>IPv6 要不要关</h3>
<p>如果代理只处理 IPv4，建议关掉 IPv6。否则部分流量会从 IPv6 直接出去，形成泄漏。</p>
<h3>访客网络能用吗</h3>
<p>不建议用来跑业务。访客网络往往共用同一出口，等于把不相干设备接进了同一条地址。</p>
<h3>换了路由器要重配吗</h3>
<p>要。配置不随设备迁移，除非新设备支持导入旧配置。</p>
